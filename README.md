## Open-source projects

### [Local Agent](https://github.com/MichalMatu/local-agent-public)

**Run ChatGPT-requested tasks on your own machines using private Git.**

Local Agent connects AI-assisted workflows to the tools and environments on your own computer. It runs tasks on a selected machine, records the results, and makes them available through your private Git repository.

Supports **macOS, Debian Linux, Raspberry Pi, and Android/Termux**, with execution limits, recovery controls, and an emergency stop.

[Explore the code and installation guide](https://github.com/MichalMatu/local-agent-public)
